# Security and Privacy Statement

This repository is a documentation-only portfolio.

It must never contain:

- Python or other executable application source;
- production or sample credentials;
- environment templates that reveal operational configuration;
- customer identifiers, phone numbers, usernames, documents, or payments;
- SQLite databases, backups, logs, caches, cookies, or browser profiles;
- server addresses, SSH material, service files, or deployment commands;
- private educational or commercial content;
- dependency manifests or automated workflows capable of reconstructing the application.

Screenshots must be reviewed and redacted before publication. Names, usernames, numeric identifiers, phone numbers, order codes, payment details, message contents, and administrator identifiers must not be visible.

Security reports should be sent privately to the repository owner rather than opened as public issues.
